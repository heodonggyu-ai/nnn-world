비교 이미지 + 코치 한마디 카드. 카톡으로 바로 보내요.

PC 블렌더에서 3D 비교영상과 힉스필드용 레퍼런스 영상을 만들어요.

사용 방법
Claude 데스크톱 앱에 블렌더를 연결했다면
블렌더 N → MCP for Blender → Connect to Claude → Claude 대화에 받은 .txt 파일을 올리고 "블렌더에서 실행하고 두 씬 다 렌더해줘"
  1. 블렌더 4.2+ → 상단 탭 Scripting
  2. Text → Open… → 받은 NNN_블렌더_….txt (복사했다면 Text → New → Ctrl+V)
  3. Text → Run Script → 씬 2개 생성
  4. 씬 NNN_비교영상 → Render → Render Animation
  5. 씬 NNN_힉스필드_레퍼런스 → Render → Render Animation
  6. 결과: 바탕화면 › NNN_motion 폴더의 mp4
교정 키는 FIX_오른손목 같은 엠프티에 있어요 → Graph Editor에서 다듬기

블렌더 레퍼런스 영상 + 회원 전신 사진 → 회원이 올바른 자세로 움직이는 AI 영상.

사용 방법
  1. 회원 사진: 정면 전신, 글러브 낀 가드 자세 (회원·미성년자는 보호자 동의)
  2. Claude로: 설정 → 커넥터 → 사용자 지정 커넥터 추가 → https://mcp.higgsfield.ai/mcp → "Kling Motion Control 3.0으로 만들어줘"
  3. 직접: higgsfield.ai → Video → Kling Motion Control 3.0
  4. 레퍼런스 영상(NNN_reference_….mp4) + 회원 사진 업로드
  5. Advanced Settings → 프롬프트 붙여넣기 → Generate
AI 영상은 동기부여용이에요. 정확한 자세 기준은 영상·카드로 설명해 주세요.
