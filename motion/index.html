블렌더를 켜고 N → MCP for Blender → Connect to Claude → Claude 데스크톱 앱 새 대화에 받은 NNN_블렌더_….txt 파일을 올리고 "이 스크립트를 블렌더에서 실행하고 두 씬 다 렌더해줘" 라고 보내면 끝이에요.

직접 하려면 ↓

  1. PC에서 블렌더 4.2 이상 실행 → 상단 탭 Scripting
  2. 받은 파일 열기: 텍스트 에디터 Text → Open… → NNN_블렌더_….txt 선택
    (복사했다면 Text → New → Ctrl+V)
  3. Text → Run Script (또는 ▶ 버튼 / Alt+P) → 씬 2개가 생겨요
  4. 화면 맨 위 씬 선택에서 NNN_비교영상 → Render → Render Animation (Ctrl+F12)
  5. 씬을 NNN_힉스필드_레퍼런스로 바꾸고 다시 Render → Render Animation
  6. 영상은 바탕화면 › NNN_motion 폴더에 mp4로 저장돼요 → 비교영상은 회원에게, 레퍼런스는 ③ 힉스필드로
✏️ 교정 키 다듬기: 아웃라이너에서 FIX › FIX_오른손목 같은 엠프티 선택 → Graph Editor에서 위치 커브 수정. 빨강(ORIG)은 회원 원본, 초록(FIX)이 교정 동작이에요.

블렌더에서 렌더한 레퍼런스 영상(교정 동작)에 회원 전신 사진을 입히면, 회원 본인이 올바른 자세로 움직이는 영상이 만들어져요. 동작은 영상에서, 얼굴·몸·옷은 사진에서 가져옵니다.

  1. 회원 사진 찍기: 정면 전신, 글러브 낀 가드 자세, 밝은 곳, 얼굴이 또렷하게 (사용 전 회원(미성년자는 보호자) 동의 받기)
  2. Claude로 하기: claude.ai 설정 → 커넥터 → 사용자 지정 커넥터 추가 → URL https://mcp.higgsfield.ai/mcp 연결 후, 대화창에 "Kling Motion Control 3.0으로 회원 영상 만들어줘" → 업로드 창에서 레퍼런스 영상·회원 사진 선택. 직접 하려면 아래 3~7번 ↓
  3. higgsfield.ai 로그인 → 상단 Video 탭
  4. 모델 선택 → Kling Motion Control 3.0
  5. 모션 레퍼런스 영상 업로드 → NNN_reference_….mp4
  6. 캐릭터 이미지 업로드 → 회원 전신 사진
  7. Output quality → 1080p · Scene source는 캐릭터 이미지(체육관에서 찍은 사진 배경을 살릴 때)
  8. Advanced Settings → 아래 프롬프트 붙여넣기 · Orientation은 reference video → Generate
배경
⚠ AI 영상은 동기부여용이에요. 손 위치·각도가 조금 달라질 수 있으니, 정확한 자세 기준은 ② 블렌더 비교영상과 ① 카드로 설명해 주세요.
