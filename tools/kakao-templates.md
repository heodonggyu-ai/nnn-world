# 탕정 엔엔엔복싱 · 카카오 알림톡 템플릿 3종

솔라피 콘솔 → 알림톡 템플릿 → 템플릿 등록 에 아래 내용을 그대로 붙여 넣어요.
- `#{...}` 는 변수예요. 글자 그대로 두세요. 회원 월드가 이 이름 그대로 값을 채워요.
- 카테고리는 "회원 정보 / 회원 가입", "구매 / 구매 완료", "회원 정보 / 정보 변경" 처럼 가장 가까운 것을 고르세요.
- 버튼은 웹링크(WL)로 추가해요. 모바일·PC 링크 모두 같은 주소를 넣어요.
- 승인 후 받은 **템플릿 ID** 를 앱스 스크립트 속성 TPL_WELCOME / TPL_PAY / TPL_HOLD 에 넣어요.

---

## 1. 가입 승인 (TPL_WELCOME)

```
#{이름}님, 탕정 엔엔엔복싱 가입이 승인되었습니다.

▶ 회원번호: #{회원번호}
체육관에 오시면 입구 출석패드에 회원번호를 입력해 주세요.

[이용수칙 안내]
1. 주 횟수 이용권(주2회·주3회 등)은 등록할 때 정한 요일에만 출석할 수 있으며, 빠진 날을 다른 요일로 옮길 수 없습니다.
2. 이용 기간은 시작일부터 연속으로 계산되며, 개인 사정으로 빠진 날은 연장되지 않습니다.
3. 정지(연기)는 3개월 등록 시 1회·최대 2주, 6개월 이상 등록 시 1회·최대 1개월까지 가능하며, 1개월 등록은 정지할 수 없습니다. 정지는 시작 전날까지 신청해야 하며 소급되지 않습니다.
4. 회원권은 본인만 이용할 수 있으며 양도·공유할 수 없습니다.
5. 환불은 관련 법령과 소비자분쟁해결기준에 따릅니다.

전체 이용약관과 이용수칙은 아래 버튼에서 확인해 주세요.
```

## 2. 등록 완료 (TPL_PAY)

```
#{이름}님, 탕정 엔엔엔복싱 등록이 완료되었습니다.

▶ 상품: #{상품}
▶ 이용 기간: #{기간}
▶ 운동 요일: #{요일}
▶ 정지(연기): #{정지규정}
▶ 결제: #{결제}

[꼭 확인해 주세요]
- 주 횟수 이용권은 정한 요일에만 출석할 수 있으며, 빠진 날을 다른 요일로 옮길 수 없습니다.
- 이용 기간은 연속으로 계산되며, 개인 사정으로 빠진 날은 연장되지 않습니다.
- 정지는 등록 기간 중 1회만 가능하며, 시작 전날까지 신청해야 합니다.

남은 기간과 출석 현황은 회원 월드에서 확인할 수 있습니다.
```

## 3. 정지 처리 (TPL_HOLD)

```
#{이름}님, 요청하신 정지(연기)가 처리되었습니다.

▶ 정지 기간: #{정지기간}
▶ 변경된 종료일: #{종료일}

정지는 등록 기간 중 1회만 가능하며, 이번에 사용하셨습니다. 정지 기간에는 출석할 수 없습니다.
```

### 참고
- 템플릿 문구는 승인 후 고칠 수 없어요. 이용수칙을 바꾸면 템플릿을 새로 등록하고 새 ID로 바꿔 넣어야 해요.
- 알림톡은 정보성 안내만 보낼 수 있어요. 할인·이벤트 같은 광고 문구는 넣지 마세요(심사 반려 사유).
